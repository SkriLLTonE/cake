# PRD — candy_cake_by_moxina

## Цель

Показать ассортимент и цены; кондитер сам обновляет меню без разработчика.

## Аудитория

Клиенты на разные события + один админ.

## Проблема

Непонятно, что есть в ассортименте и сколько стоит.

## MVP

### Публичная часть (RU + UZ, mobile-first)

- Home, About, Catalog (Collection / Bento), Contacts
- Карточка: фото, название, размер, цена (тыс. UZS), атрибуты
- Фильтр: бюджет-пресеты + начинка + ягоды/фрукты + тип теста
- Контакт: только Telegram / Instagram (без формы и оплаты)

### Админка

- Логин/пароль, сессия
- CRUD категорий, товаров, атрибутов, бюджетных корзин
- Загрузка фото

### Вне MVP

Корзина, оплата, форма заявки, Telegram-бот, email-подписка.

## Дизайн

Светлая кондитерская. Палитра: вишнёвый, бежевый, белый, шоколадный. Новый UI.

## Стек

Next.js App Router, Prisma, PostgreSQL через Docker Compose (только БД), next-intl, локальный upload.
